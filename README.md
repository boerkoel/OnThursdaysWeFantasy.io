# On Thursdays We Fantasy

**The Officially Unofficial League Record Book**

A fantasy football analytics site for the **On Thursdays We Watch Football** league.

## What this will become

- League standings and team profiles
- Weekly scores and results
- League leaders and records
- Fun awards like Heartbreak, Blowout King, Bad Beat, and Bench Warmer
- Season timelines and historical champions
- Automatically refreshed ESPN data

## Data pipeline

```
ESPN Fantasy Football
        ↓
GitHub Actions
        ↓
Stats / JSON data
        ↓
GitHub Pages
        ↓
On Thursdays We Fantasy
```
